SENA LSA64 - VERSION PORTABLE PARA WINDOWS
==========================================

INICIO RAPIDO
1. Extrae toda la carpeta del ZIP en una ubicacion escribible.
2. Ejecuta run.bat.
3. La primera ejecucion necesita Internet para instalar las dependencias.
4. Se abrira http://127.0.0.1:8000 en el navegador.
5. Pulsa "Iniciar camara". Cierra la ventana de consola para apagar el servidor.

REQUISITOS
- Windows de 64 bits.
- Python 3.10, 3.11 o 3.12 de 64 bits y el Python Launcher (py).
- Conexion a Internet la primera vez; despues, el entorno virtual queda dentro
  de esta carpeta y puede reutilizarse.
- Camara compatible con el navegador.

El modelo LSA64 esta incluido y ocupa aproximadamente 18 MB. Los videos del
dataset no estan incluidos. La aplicacion reconoce senas aisladas y muestra
etiquetas orientativas en espanol; no traduce frases ni esta validada para uso
linguistico, educativo o de accesibilidad.

Si se usa desde otro dispositivo de la red local, consulta las instrucciones de
HTTPS y certificados en AVISO-LSA64.txt y en la documentacion del proyecto.
